# Chronicle.Plugin.IGDB

Metadata provider plugin for **IGDB**.

## Design Document

Full design documentation:
[docs/plugins/PLUGIN_IGDB.md](https://github.com/thegoddamnbeckster/Chronicle/blob/develop/docs/plugins/PLUGIN_IGDB.md)

## Supported Media Types

`game`

## Quick Start

1. `dotnet build`
2. Copy `Chronicle.Plugin.IGDB.dll` to your Chronicle `plugins/active/` directory
3. Restart Chronicle
4. Navigate to **Settings -> Plugins -> IGDB**
5. Configure required settings (see design doc)
